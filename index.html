Add your game

Made a small game with AI? Add it to the arcade with one pull request.

  1. Fork the repo and put your game in games/your-slug/index.html.
  2. Add an entry for it to games.js.
  3. Open a PR titled Add game: Your Title.

Your game should run in the browser with no build step, load nothing from other sites (no trackers, ads or remote APIs), stay under 5 MB, be safe for everyone, and be your own idea, not a clone. Automatic checks run on every PR.
